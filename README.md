# VivaLeve

Aplicativo mobile de bem-estar que ajuda pessoas adultas a organizar hábitos, metas e sugestões alimentares educativas de forma simples.

> O VivaLeve não prescreve dietas, calorias, porções ou tratamentos. Ele não substitui o acompanhamento de nutricionista ou médico.

## Primeira versão

- Coleta objetivo, peso informado, meta de mudança e nível de movimento
- Mostra uma rotina de hábitos e sugestões flexíveis por refeição
- Salva apenas os check-ins de hábitos no dispositivo para acompanhar o dia
- Destaca quando há necessidade de acompanhamento profissional
- Mostra um perfil-resumo do ponto de partida

## Segurança e escopo

O app é destinado a educação alimentar e organização de hábitos para adultos. Gestação, alergias, condições de saúde, transtornos alimentares e necessidades nutricionais específicas exigem avaliação profissional individualizada.

O app não salva peso, metas ou informações de saúde. Os check-ins de hábitos são guardados localmente no dispositivo e podem ser apagados ao limpar os dados do aplicativo.

As sugestões priorizam variedade, alimentos in natura ou minimamente processados e escolhas sustentáveis; elas não são uma dieta clínica. A abordagem segue princípios do [Guia Alimentar para a População Brasileira](https://www.gov.br/saude/pt-br/composicao/saps/promocao-da-saude/guias-alimentares/guias-alimentares) e da [OMS sobre alimentação saudável](https://www.who.int/en/news-room/fact-sheets/detail/healthy-diet).

## Tecnologias

- React Native
- Expo
- TypeScript

## Executando

```bash
npm install
npm run start
```

Abra o projeto pelo Expo Go no celular ou por um emulador Android/iOS.
